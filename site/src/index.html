Local connector. Approved exports only.

  1. Export and approve. The controller exports the report to Excel and lists the file in approved.json with its SHA-256 and a few control totals read off the rendered report.
  2. Check before reading. The server refuses a file that changed after approval, misses a reporting unit, has totals that do not tie beyond the written rounding rule, or does not match its control totals.
  3. Ask in Claude. A local C# connector (.NET 10, official MCP C# SDK 2.2.0) that Claude starts on the same machine and that reads the approved exports folder, for example on a network share. Built as a Claude Desktop extension package, tested with Claude Code as the MCP client. Six read tools, arithmetic included; no write tool, no path, no SQL.

Privacy. The connector runs locally and reads approved exports without modifying them. Returned figures and their report context are sent to Anthropic through Claude; your organization's Claude data policies apply.

What this proves, and what it does not. This demonstrates the connector and its checks on synthetic data. Compatibility with your exports and diagnosis of your report errors require validation on your system. The conversations were recorded on September 30, 2026 with Claude Code as the MCP client; the extension package has not been installed in Claude Desktop yet, and the Windows package is built, not tested on a clean Windows machine.

If a report error looks like one of these

“Object reference not set to an instance of an object” when generating
An Excel link in the row definition pointing to a CALC column, or a summary level of the tree with a mask in the Dimension column. KB2976908
“Index was out of range” in the Dimension Value integration task
Account segment references in GL40200 missing from SY00300 or GL00100. KB3029952
“A problem in the data provider framework” opening a row or column definition
A blank, duplicate or reserved name among General Ledger user-defined fields and Analytical Accounting dimensions. KB2776705
Process Service stops and restarts continually
The 32-bit SP3 CLR Types for SQL Server 2012 installed without the 64-bit one. KB3144801

First move: compare one failing report with a working one under the same company, period and user, capture the exact error and its Application event, then check the row, column and tree definitions it points to.
